# RevenueDot

**The open-source RevenueCat alternative.**<br>
Self-hosted in-app purchase and subscription infrastructure for iOS, Android, React Native, Flutter and the web.<br>
Works with the RevenueCat SDK: change one line, keep your app code.

**[Start free on RevenueDot Cloud](https://app.revenuedot.app/signup)** · [revenuedot.app](https://revenuedot.app) · [Docs](https://revenuedot.app/docs) · [Main repository](https://github.com/revenuedot/revenuedot)

</div>

### What we build
- **[revenuedot](https://github.com/revenuedot/revenuedot)**: the server and dashboard. App Store, Google Play, Amazon Appstore and Stripe purchases, entitlements, offerings, [paywalls](https://revenuedot.app/features/paywalls), [A/B experiments](https://revenuedot.app/features/experiments), [web checkout](https://revenuedot.app/features/web-billing), [43 charts](https://revenuedot.app/charts), [36 integrations](https://revenuedot.app/integrations) and webhooks. Use [RevenueDot Cloud](https://app.revenuedot.app/signup), free up to $10,000 a month in tracked revenue, or self-host with Docker and Postgres.
- **SDKs** (MIT forks, same API as RevenueCat): [iOS](https://github.com/revenuedot/purchases-ios) · [Android](https://github.com/revenuedot/purchases-android) · [React Native](https://github.com/revenuedot/react-native-purchases) · [Flutter](https://github.com/revenuedot/purchases-flutter) · [Web](https://github.com/revenuedot/purchases-js) · [Capacitor](https://github.com/revenuedot/purchases-capacitor) · [Kotlin Multiplatform](https://github.com/revenuedot/purchases-kmp) · [Unity](https://github.com/revenuedot/purchases-unity) · [Cordova](https://github.com/revenuedot/cordova-plugin-purchases)
- **AI-native**: [MCP server](https://github.com/revenuedot/mcp) for Claude, ChatGPT and Cursor, and [agent skills](https://github.com/revenuedot/agent-skills) that migrate an app from RevenueCat.

### Why RevenueDot
- Free on Cloud up to $10,000 a month in tracked revenue, and no revenue share when you self-host. [Compare with RevenueCat](https://revenuedot.app/compare/revenuedot-vs-revenuecat).
- Your purchase data in your own cloud and region.
- The same API and webhook payloads as RevenueCat, so migration is one line and an import.
