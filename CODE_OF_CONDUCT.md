# Code of conduct

RevenueDot follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal attacks and discrimination are not allowed in any RevenueDot space.

Report problems privately to the maintainers through GitHub (a private vulnerability report or a direct message to an organization owner). Maintainers may remove comments, lock threads or ban accounts that break these rules.
